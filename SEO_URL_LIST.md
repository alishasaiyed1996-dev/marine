## How to submit these

1. **Bulk (all of them):** Search Console → Sitemaps → submit `sitemap.xml`. This covers every URL below in one step; you do not need to submit them individually.
2. **Manual (the important ones):** Google’s *Request Indexing* is rate limited to roughly 10 URLs per day, so use it only on the static pages and hubs below — not on the 1,074 product URLs.
3. **Check what actually landed:** run `npm run gsc:audit` for per-URL index status, or use URL Inspection in Search Console.

> **About the Status column.** It is what the last Googlebot crawl saw (`reports/index-audit-2026-10-27.json`, 2026-10-27). A bold **503** does *not* mean the URL is broken — every one of those pages serves a normal 200 when requested on its own. It means the storefront returned its outage shell *under crawler load*, because an API rate limit (100 requests/minute per IP) is converted into 503 + `noindex`. This is the single biggest indexing blocker, so fix it before expecting these URLs to be indexed. Details and the reproduction: `SEO_RANKING_RESEARCH.md` §1.
